# LensStories

A cinematic, responsive visual storytelling journal built with semantic HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in any modern browser. No build step or dependency installation is required. For a local HTTP server, run:

```bash
npx serve .
```

## Included

- Dramatic featured-story hero and editorial introduction
- Responsive visual story grid with category filters and text search
- Seven story experiences presented in accessible native dialog overlays
- Behind-the-scenes editorial section, quote interlude, and media-contact footer
- Keyboard focus states, semantic navigation, alt text, and reduced-motion support
- Remote Unsplash photography and Google Fonts; a network connection is needed for those assets

## Notes

The copy and media contact address are sample content for the LensStories concept. Replace `media@lensstories.example` with a monitored inbox before publishing. Story text should be reviewed against verified brand impact claims before using the site as an official corporate publication.
