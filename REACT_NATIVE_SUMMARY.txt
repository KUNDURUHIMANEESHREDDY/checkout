================================================================================
                              HOW TO RUN
================================================================================

1. Navigate to project:
   cd /workspace/KUNDURUHIMANEESHREDDY__checkout/react_native_app

2. Install dependencies:
   npm install
   # or
   yarn install

3. Start development server:
   npx expo start

4. Run on device:
   - Android: Press 'a' or scan QR code with Expo Go
   - iOS: Press 'i' or scan QR code with Expo Go
   - Web: Press 'w'

================================================================================
                              IMPORTANT NOTES
================================================================================

⚠️  OCR Implementation:
    The current implementation uses MOCK OCR for demonstration.
    You need to implement real OCR for production.
    
    Recommended: Use expo-mlkit or Google ML Kit
    File to update: src/hooks/useOCR.ts

⚠️  Camera Permissions:
    Already configured in app.json for Android.
    For iOS, you may need to add camera usage description.

⚠️  PDF Generation:
    Uses pdf-lib which works in Expo.
    For better performance, consider native modules.
